# cloud-study-api

云奕学的本地 FastAPI 服务。

当前实现包括：

- 仓库内置技能包启动门禁；
- SQLAlchemy 2、Alembic 和 SQLite；
- 受限诊断访谈预览；
- 与诊断绑定的本地规划预览；
- 来源元数据检查和变化候选；
- `algorithm@0.2.0` 的受限学习执行、追加式尝试与纠错；
- 六维受限证据、独立待办标记和固定递增复习；
- 用户可选择考试、纯学习、就业、接单、产品化或其他目标；
- 本地确定性准备度门禁、不可变策略与显著标记的合成市场快照；
- 就业、接单、产品化三路径合成比较和追加式决定审计；
- 技能包首次持久化引用内容锁和不可变执行锁；
- 站内通知、SMTP 发件箱和 Windows 凭据引用；
- AI 供应商档案接口；5B 只允许锁定 DeepSeek 官方
  `deepseek-v4-flash`，其他真实供应商调用仍被禁用；
- 受管官方市场来源、robots/HTTPS/响应大小门禁、净化短摘录和来源失败状态；
- 外部 AI 总开关、逐次确认、官方价格表精确复核、月/日/单次费用硬上限和人工复核审计；
- DeepSeek 独立适配器、原子付费调用抢占、调用前保守 token 上界和预算预留；
- 版本化市场研究注册表、技能/版本/能力范围/用户目标和可选准备度评估锁；
- 原始响应、完整规范化正文和短摘录三类哈希，以及模板变化与正文变化的独立状态；
- 路径证据能力、独立来源组和本次内容相关性门禁；当前三条路径只有背景能力时固定返回
  `indeterminate`；
- `limited_background_v1` 只允许模型返回背景摘要、来源 ID、不确定性与限制；路径状态
  和 `no_change` 内容影响由后端确定性生成，模型不能决定结论状态；
- 无效模型内容只记录失败阶段、受管结构摘要、校验类别、内容哈希以及已知 token/费用，
  不保存无效响应原文、未知键名或未知值；
- 付费调用持久化 attempt、5 分钟执行租约、启动恢复、未知收费最坏记账和显式对账结束；
- 来源目录与预算策略不可变快照、有效来源引用校验、来源撤回后的综合失效及可查询审计历史；
- 来源目录 `1.2.0` 分别追踪逐来源最近访问与最近成功快照；成功刷新间隔 7 天，失败冷却
  24 小时且无人工绕过，部分失败重试只访问已到期来源；
- 发送前外发材料预览与逐项摘录删除；预览和实际综合请求复用同一净化材料结构；
- 请求模型与响应声明模型分别审计；响应缺失或不等于 `deepseek-v4-flash` 时停止并保守记账；
- 官方价格表按价格标签与模型相对列解析，兼容 `rowspan` 分组列；仅允许尚无 attempt、
  dispatch、响应、token 或费用证据的 `pricing_changed_or_unverifiable` 失败经单独确认恢复，
  恢复后仍需再次确认付费综合；
- 会改变后端状态的失败响应由界面保留原错误并重新读取最新研究与审计状态；
- Playwright 通过独立离线测试宿主验证成功、人工复核、删除失效和模型不一致流程，
  不访问真实来源或付费模型。

第四里程碑 4A 已完成本地实现和发布就绪验证。代码和文件仍不会执行或上传，学习执行不调用外部 AI，不提供独立人工审核通过，也不生成整体掌握结论。4B 隔离代码运行必须另行确认。

第五里程碑 5A 已通过完整本地发布就绪验证。它自身仍不会访问真实市场或调用外部
AI。5B 已获独立授权并在单独分支实现受控真实研究；5B 结果不会自动改写 5A
准备度、技能包或学习计划。5C 与真实实验仍未授权，有限证据不会被提升为真实交付资格。
