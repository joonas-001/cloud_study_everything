# 提交issues请看这里

## 简要提交流程

1. 先搜索是否已有相同问题；安全漏洞、凭据泄露或越权问题不要公开提交；
2. 在下方选择最合适的一栏，点击“填写并提交”打开已预填模板；
3. 补齐信息并删除答案、完整代码、凭据、身份、私有地址、本地路径和完整日志等敏感内容；
4. 最后检查标题、正文和自动附加的标签，点击 GitHub 的“Submit new issue”完成提交。

| Bug／缺陷 | Feature Request／功能建议 | Other／其他 |
| --- | --- | --- |
| 可复现故障、错误结果或回归 | 新能力、体验或运维改进 | 内容／证据、文档、使用问题或暂时无法归类的事项 |
| 自动附加 `bug` 标签 | 自动附加 `enhancement` 标签 | 自动附加 `question` 标签，等待分诊 |
