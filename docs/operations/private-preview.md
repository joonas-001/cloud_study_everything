# 单用户私有预发布运行手册

> 本手册是 6A 代码交付物，不构成创建云资源、付费、迁移真实数据或上线授权。
> 以下云端步骤只能在项目所有者单独授权 6B 后执行，且 6B 只使用合成数据。

## 1. 固定边界

- 平台候选固定为腾讯云轻量应用服务器新加坡区，单实例 2 vCPU、2 GiB、40 GiB；
- 只通过 Tailscale Serve 的 tailnet 私有 HTTPS 地址访问，不开放注册或公网业务端口；
- 身份只接受运行时配置的一个 Microsoft 个人账号完整登录名；
- Next.js 和 FastAPI 都只监听 `127.0.0.1`，FastAPI 只信任来自回环代理的身份头；
- SQLite 位于持久磁盘；首次私有预发布只使用合成数据库；
- 远程 Runner、真实 AI、真实来源访问和邮件全部关闭；
- 月度费用硬上限为 ¥50，预期约 ¥32，禁止自动充值和自动扩容；
- 不购买自定义域名，不制作公开品牌入口。

## 2. 项目所有者需要完成的事项

在授权 6B 后，项目所有者本人需要：

1. 确认用于白名单的 Microsoft 个人账号完整邮箱，并为账号开启 MFA 和可用的恢复方式；
2. 登录腾讯云与 Tailscale；任何验证码、支付确认和账号恢复操作均由本人完成；
3. 在腾讯云结算页再次确认新加坡实例的实际价格、期限、流量和续费方式；
4. 确认总价不超过 ¥50/月、关闭自动续费或自动充值，并设置 50%/80% 费用告警；
5. 在离线位置生成和保存备份私钥，至少保留两份独立副本；私钥不得上传到主机；
6. 只向受限配置文件写入白名单邮箱和实际 tailnet 地址，不把它们提交到 Git；
7. 完成首次合成数据库恢复演练并亲自确认报告，再决定是否进入 6C。

账号、验证码、支付方式、真实邮箱和备份私钥不应发送给编码代理。

## 3. 6B 执行顺序

1. 再次读取腾讯云、Tailscale 和对象存储的官方价格与限制；
2. 由项目所有者确认结算页总价后创建单个新加坡实例；
3. 创建无登录 Shell 的 `cloud-study` 服务账号和以下目录：
   `/opt/cloud-study/app`、`/var/lib/cloud-study`、`/var/backups/cloud-study`、
   `/etc/cloud-study/secrets`；
4. 安装精确的 Node.js 24、Python 3.14.3、pnpm 11 和 uv 0.11，并使用锁文件安装；
5. 复制 `deployment/private-preview.env.example` 到主机受限路径，填入运行时值并设为
   所有者只读；
6. 生成合成数据库并迁移到 Alembic `0010`，确认外部 AI 和邮件均为关闭；
7. 安装 `deployment/systemd` 中的单元和独立 journald 配置；Web 单元必须通过
   `tools/run_private_preview_web.mjs` 启动，不得另行猜测 pnpm shim 路径；
8. 先运行 `tools/deployment_preflight.py`，任何失败都停止；
9. 启动 API、Web 和备份定时器；确认只有回环端口 `3000`、`8000`；
10. 在 Tailscale 管理端建立只允许精确 Microsoft 所有者账号访问该节点和 Serve
    端口的 grant／访问策略；未配置策略时不得继续；
11. 配置 Tailscale Serve 将私有 HTTPS 地址转发到 `127.0.0.1:3000`；
12. 用无身份、错误身份和正确身份分别验证页面、API 和 Tailscale grant；
13. 创建加密备份，恢复到新数据库路径，核验摘要、外键、行数和 Alembic 版本；
14. 配置加密备份的异机副本；异机副本未完成前不接受灾难恢复门禁；
15. 记录实际费用、流量、版本和验证证据，不迁移真实数据。

## 4. 配置与文件权限

私有值只允许存在于主机的 `/etc/cloud-study/private-preview.env`，权限应为 `0600`。
凭据目录应为 `0700`，单个凭据文件应为 `0600`。应用只读取该目录，不支持通过页面写入、
替换或删除云端凭据。SQLite 中的既有凭据引用保持不变；主机文件名使用引用的 SHA-256
映射，避免把引用中的路径分隔符当作文件路径。可使用以下只读工具计算文件名：

```text
python tools/credential_file_name.py --reference <SQLite中的凭据引用>
```

备份公钥可位于主机；私钥必须离线。SQLite、备份目录和日志均不得包含 API 密钥。正式
执行前应运行：

```text
python tools/deployment_preflight.py
python tools/manage_backup.py inspect --backup <加密备份路径>
```

预检只读，不迁移数据库、不联网，也不创建资源。备份恢复必须指定一个尚不存在的目标文件，
工具会拒绝覆盖现有数据库。

## 5. 身份、撤销与紧急停止

Tailscale Serve 是唯一受信任身份代理。Next.js 页面代理和 FastAPI API 都只在身份头
与单一白名单完全匹配时放行；API 还要求请求来自回环地址，所有状态修改要求精确的
`https://*.ts.net` Origin。直接访问 API、伪造身份头、使用其他 tailnet 身份或跨站
提交都会被拒绝。6B 验收必须分别证明页面、API 和 Tailscale grant 对错误身份均拒绝。

需要立即撤销访问时，按以下顺序操作：

1. 在 Tailscale 管理端禁用设备或移除允许访问的身份；
2. 停止 `cloud-study-web` 和 `cloud-study-api`；
3. 保留 SQLite 与审计历史，只暂停服务；
4. 如怀疑凭据泄漏，在供应商侧吊销密钥，再替换只读凭据文件；
5. 如怀疑数据库损坏，从已验证的加密备份恢复到新路径，禁止覆盖原文件；
6. 记录事件时间、原因、操作和校验结果，不记录敏感正文。

Microsoft/Tailscale 账号不可恢复、身份头行为变化、tailnet 地址变化或价格无法确认时，
私有预发布必须保持停止。

## 6. 费用停止条件

- 50%：通知项目所有者并复核当月预测；
- 80%：停止新增付费资源与所有可选外部能力，检查异常流量；
- 预测或实际达到 ¥50：停止 Web/API 以阻止新增流量，并由项目所有者处理账单；
- 价格变化、无法估价、余额不足或出现未确认计费项：停止，不自动充值、不静默换平台。

云厂商账单告警不等于强制扣费上限。6B 必须实际验证告警和停止流程；在此之前，
“¥50 硬上限”是购买与运行门禁，不能表述为已由云平台技术保证。
