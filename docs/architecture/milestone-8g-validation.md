- API 就绪探测从端口存在改为真实 `/health`；

- 首页等待真实“今日概览”及其六个 API 请求完成后再执行跨区重复导航。

没有增加错误白名单。正式完整矩阵随后通过 Chromium 桌面、Pixel 7 移动、平板 Chromium

失败而后续重复通过；该限制不影响本次正式完整矩阵结论，但不能被描述为所有任意启动顺序
都已证明无竞态。
