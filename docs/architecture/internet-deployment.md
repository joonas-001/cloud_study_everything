# 第六里程碑：单用户互联网部署评估与受控上线

> 状态：6A 已正式交付完成；6B 云资源创建、付费、真实数据迁移和上线仍未授权
> 更新日期：2026-08-09
> 交付基线：`main@b2b816f`
> 首版访问范围：仅项目所有者本人，不开放注册或公开使用

## 1. 目标

第六里程碑的目标不是把本地开发服务直接暴露到互联网，而是建立一条经过身份验证、
最小权限、可迁移、可回滚且成本受控的单用户远程访问路径。

完成后应能够证明：

1. 未登录者不能访问用户数据或业务 API；
2. 本地已有的诊断、学习、来源、证据、市场研究和实验历史可以完整迁移及恢复；
3. API 密钥不会进入数据库、前端、构建制品或日志；
4. 外部 AI、来源访问和代码 Runner 继续遵守现有开关、预算、版本和隔离边界；
5. 部署失败、费用异常或安全事件发生时，可以停止服务并恢复到本地版本；
6. 所有部署结论都由真实验证支持，不把“页面能打开”等同于安全上线。

第五里程碑中需要当前用户亲自取得的 Runner、保持、作品和真人评审证据继续保持阻塞。
互联网部署不会补齐、替代或降低这些证据要求。

## 2. 已确认事实

- 初始用户仍只有项目所有者本人；
- 首版不设计付费功能，不开放公开注册；
- 本地技术栈为 Next.js、FastAPI、SQLite、SQLAlchemy 2 和 Alembic；
- Node.js 必须保持 24 LTS，Python 必须保持 3.14.3；
- 前端继续使用 pnpm，后端继续使用 uv 和锁文件；
- 本地密钥当前保存在 Windows 凭据管理器，SQLite 只保存凭据引用；
- 互联网部署前必须增加身份验证和访问控制；
- 数据迁移必须保留已有学习、来源、评估和审计历史；
- 未经确认不得创建云资源、开通付费能力或发布公开网站；
- 4B Runner 的 Docker 安全边界和 5B 的外发、来源及费用边界仍然有效。

## 4. 推荐阶段

### 6A：决策包与本地部署准备

本阶段不创建任何互联网资源，不产生部署费用。

已实现交付物：

- 版本化部署策略、Schema、确定性检查和 CI 门禁；
- 私有身份代理边界、Next.js/FastAPI 双层精确所有者白名单、回环来源和 CSRF Origin 校验；
- Next.js 同源 API 代理、安全响应头、仓库受控启动器和只监听回环的 systemd 单元；
- 云端只读文件凭据适配器；本地 Windows 凭据管理器实现保持不变；
- 远程 Runner 和外部 AI、来源、邮件的稳定硬停止；
- SQLite 一致性快照、加密、保留、恢复与篡改拒绝；
- Python 3.14.3、Node 24、pnpm 11、uv 0.11、Schema 和外发状态只读预检；
- 费用策略、威胁模型、紧急停止、备份恢复和 6B 操作手册。

完成门禁：

- M6-D01 至 M6-D10 已由项目所有者确认；
- 本地 `release-readiness` 保持成功；
- 没有创建云资源、域名、账号或付费订阅。

### 6B：合成数据私有预发布

本阶段必须获得单独实施和资源创建授权。环境只允许项目所有者访问，只使用合成数据，
默认关闭外部 AI、真实邮件、真实来源访问和远程 Runner。

交付物：

- 基础设施和应用版本锁；
- TLS、身份验证、会话失效、CSRF/CORS 和安全响应头；
- API 与数据库仅通过受限内部网络通信；
- 云端密钥适配器，密钥不返回前端、不进入数据库或日志；
- `/health` 与受保护的 readiness 检查分离；
- 最少化日志、审计、费用告警和紧急停止；
- 桌面和移动端登录、退出、过期、拒绝访问和恢复 E2E。

完成门禁：

- 未登录和非白名单身份均无法访问业务页面和 API；
- 合成数据库可备份、删除并恢复；
- 费用没有超过确认的硬上限；
- 安全检查、契约检查和完整 CI 成功；
- 项目所有者明确接受预发布结果。

### 6C：真实数据迁移演练与 Runner 决定

本阶段先使用本地数据库的加密副本进行离线或隔离演练，不直接替换唯一真实数据库。

迁移必须：

- 在迁移前停止写入并生成带时间、Schema 版本和摘要的备份；
- 使用正式 Alembic 历史，不使用 `create_all`；
- 校验表、行数、关键外键、不可变锁、事件顺序和摘要；
- 抽查诊断、规划、学习、来源、市场研究和实验历史；
- 完成反向恢复，证明本地版本仍可继续使用；
- 记录迁移开始、结束、操作者、输入摘要、结果和失败原因；
- 不把原始密钥、凭据或不必要的敏感日志带入迁移制品。

Runner 采用独立门禁：

- 预发布和迁移演练默认禁用远程代码执行；
- FastAPI 进程不得直接执行代码或挂载 Docker Socket；
- 如果确认启用远程 Runner，必须使用独立执行边界，重新验证精确镜像摘要、断网、
  非 root、只读根、资源限制、输出限制、并发、超时和失败清理矩阵；
- 云端基础设施验证仍不能成为用户个人 `verified` 或 `retained` 证据。

完成门禁：

- 迁移与回滚演练全部成功；
- 数据差异为零或每项差异均有明确、经确认的解释；
- Runner 是否进入首次上线范围已由项目所有者决定；
- 尚未把生产流量切换到互联网环境。

### 6D：所有者单用户受控上线

本阶段需要最后一次单独授权。不得因为 6A 至 6C 成功就自动上线。

上线顺序：

1. 冻结本地写入并创建最终加密备份；
2. 部署精确提交和配置摘要；
3. 执行正式迁移和完整性校验；
4. 验证 TLS、登录、退出、会话撤销和所有业务 API；
5. 默认关闭外部 AI、邮件和远程 Runner，再逐项由用户开启；
6. 执行桌面／移动关键路径烟雾测试；
7. 开启费用、错误和安全事件告警；
8. 在约定观察期内保留本地只读回退；
9. 任一停止条件触发时回滚，不静默带病运行。

完成标准：

- 只有项目所有者能够访问；
- 真实数据完整迁移且备份恢复已验证；
- 身份验证、密钥、网络和日志边界通过安全复核；
- 关键页面和 API 在桌面、移动端均成功；
- 费用和资源占用在已确认范围内；
- 合并后主线 CI 和生产烟雾验证成功；
- 运维、备份、恢复、密钥轮换和下线说明可执行。

## 5. 安全与隐私最低要求

- 所有互联网流量使用 TLS；
- 除最小健康检查外，页面和 API 默认拒绝未认证请求；
- 认证只允许项目所有者的显式白名单身份；
- 会话 Cookie 使用 `Secure`、`HttpOnly` 和合适的 `SameSite`；
- 状态修改请求具有 CSRF 防护，CORS 不允许通配来源；
- 登录、外部调用、导出和高成本操作有速率限制和审计；
- 数据库、Runner、管理端口和调试界面不直接暴露公网；
- 云端凭据使用独立适配器和最小权限，不能复用 Windows 凭据引用冒充真实密钥；
- 备份和迁移制品加密，下载、保留和删除有审计；
- 日志默认不保存代码正文、AI 原始响应、密钥、收入金额或不必要的个人输入；
- 依赖、基础镜像和部署制品使用锁定版本及摘要；
- 安全事件可以立即暂停登录、外部发送、Runner 或整个服务，同时保留审计。

## 6. 数据与可移植性

平台选择不能使数据只能通过供应商私有界面读取。至少提供：

- 数据库原生备份；
- 版本化 JSON 导出；
- 收入记录的既有 JSON/CSV 隐私导出；
- 技能包、来源目录、策略和契约的精确版本清单；
- 部署配置摘要，但不包含密钥；
- 可在新环境中验证的备份摘要和恢复报告。

如果 SQLite 迁移到其他数据库，必须新增正式 Alembic 路径和双向迁移演练，不能修改历史
迁移来伪造兼容。

## 7. 费用门禁

任何平台调研必须记录：

- 免费额度是否长期有效及其限制；
- 固定月费、按量计算项、网络流量、存储、备份和日志费用；
- 超额后是停止、降级还是继续计费；
- 价格来源、币种、税费、发布日期和检索日期；
- 账号欠费、价格变化或无法估价时的停止行为。

在项目所有者确认具体数字前：

- 不创建需要绑卡或持续收费的资源；
- 不启用自动充值；
- 不依赖“通常免费”作为预算；
- 不把免费额度视为可用性保证；
- 不产生真实部署费用。

## 9. 明确非目标

第六里程碑首版不包括：

- 多用户、团队、组织、角色管理或公开注册；
- 订阅、支付、付费课程或商业化；
- 公开 API、第三方集成市场或第三方技能包自动安装；
- 自动投递、联系、发布、签约、交易或收入保证；
- Logo、商标、公开品牌发布和大规模营销；
- 为适配平台擅自降低 Node、Python、Runner 或技能包版本；
- 把 Docker Socket 暴露给 API 或互联网；
- 未经验证把本地 Runner 原样搬到公网主机；
- 自动删除本地数据库或唯一备份；
- 在未确认预算时启用持续收费服务。

## 10. 6A 威胁模型与剩余门禁

| 威胁 | 6A 控制 | 仍须在 6B 真实验证 |
| --- | --- | --- |
| 公网绕过身份代理 | Web/API 回环监听，API 拒绝非回环请求 | 云防火墙和监听端口实测 |
| 伪造或越权 Tailscale 身份 | 页面与 API 精确单账号匹配，API 只信任回环代理 | owner-only grant、Serve 实际身份头、撤销和错误身份 |
| 跨站状态修改 | 精确私有 Origin，CORS 不使用通配业务来源 | 浏览器桌面／移动拒绝路径 |
| 云端密钥泄漏 | 固定只读目录、禁止符号链接和宽权限、不返回原文 | 主机权限、日志和制品扫描 |
| 外部调用或费用意外扩大 | 策略和路由硬停止，systemd 只允许回环网络 | 腾讯云告警、实际账单和停止演练 |
| 远程代码执行扩大攻击面 | 远程 Runner 禁用且不调用 Docker 清理后端 | 合成预发布确认无 Docker Socket/容器 |
| SQLite 损坏或主机丢失 | 一致性快照、认证加密、摘要/外键/行数恢复校验 | 加密制品异机复制与实机恢复 |
| 日志泄露敏感正文 | API 访问日志关闭、独立 7 日 journal | 主机 journal 内容和到期清理 |
| Microsoft/Tailscale 账号丢失 | 单账号门禁和紧急停止手册 | MFA、恢复方式、设备/身份撤销 |

6A 不证明腾讯云运行成功，也不证明 Tailscale、费用告警或异机备份已配置。下一阶段仍为
阻塞状态；只有项目所有者另行授权创建 6B 资源后，才可在单个新加坡实例上使用合成数据
验证。真实数据库迁移属于 6C，所有者单用户上线属于 6D，两者都需要再次单独授权。
