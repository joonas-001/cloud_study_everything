## 1. 结论与边界

9D 已完成项目所有者授权范围内的合成隐私候选。实现只处理合成身份、合成数据和本地候选
环境；没有创建或连接 Clerk 资源，没有接收真实身份、邀请、邮件或个人数据，没有调用外部
AI/来源，没有修改 6D 生产环境，也没有创建云资源或产生新增费用。

四份政策文本明确标为候选稿，不构成法律意见、合规认证或对真实用户生效的条款。专用支持/
隐私联系渠道尚未配置，真实供应商的数据地区、合同和退出路径也未完成专业复核。因此 9D
技术候选完成不等于可以邀请真实用户；这些事项仍是 9G 前硬门禁，9E–9H 仍须分别授权。

## 2. 受管政策与分项选择

- `milestone-9d-candidate@1.0.0` manifest 管理隐私告知、服务条款、可接受使用规则和供应商
  清单；接受记录绑定文档类型、版本、完整 Markdown 正文 SHA-256 和接受时间；
- 候选文本逐类说明身份、学习记录、代码/文本、能力证据、目标/收入、凭据引用、支持内容、
  日志、隐私请求和备份的目的、必要性、位置、接收方、期限和删除方式；
- 外部 AI、真实来源、邮件和支持诊断分别选择且默认关闭。9D 只记录选择，`effective_enabled`
  固定为 false，不允许选择绕过供应商、预算、隐私或上线门禁；
- 用户内容和用户自己创作的成果不自动归平台所有；用户可以合法利用自己的技能和成果就业、
  接单、销售或创业。未经许可商业化云奕学软件本身的限制与用户成果权利明确分开。

## 3. 可执行权利流程

| 能力 | 候选行为 | 关键限制 |
| --- | --- | --- |
| 访问 | 返回当前主体元数据、数据类别和 43 张私有表逐表数量 | 默认不返回正文 |
| 更正 | 修正无操作时限和四类用途选择并记录请求摘要 | 只允许受管字段 |
| 导出 | 明确敏感导出确认后生成当前用户全量 JSON、范围、时间和 SHA-256 | 排除密钥原文、会话/事务秘密、限流键、他人及全局受管内容 |
| 删除请求 | 最近 5 分钟 MFA 后进入 7 天等待并立即撤销会话 | 唯一所有者须先转移职责 |
| 撤销删除 | 等待期内通过允许 deletion-pending 的最近认证会话恢复 | 到期后不可撤销 |
| 到期执行 | 所有者运营角色事务化清除用户私有表、身份绑定、会话和角色 | 失败整体回滚并记录固定失败码 |
| 墓碑 | 只保留作业/内部主体标识、完成时间、备份最晚过期和 180 天保留界限 | 不保留正文、邮箱、外部 subject 或凭据 |

## 4. 备份删除传播

删除完成后可导出受控删除账本。账本包含固定格式/版本、最小墓碑记录和规范 JSON SHA-256；
SHA-256 只检测意外损坏，不能替代受控来源与访问保护。恢复任何可能早于删除的加密备份后，
必须先校验并重放当前受控账本，再允许服务使用恢复库。重放会再次清除恢复出的私有记录、身份、
会话和角色，恢复/补齐墓碑，并把旧备份中的同一 `waiting` 作业归并为 `completed`，防止再次
执行或恢复登录。

自动化测试真实创建 RSA-OAEP-SHA256 + AES-256-GCM 加密备份，在删除完成后解密恢复旧库并
重放账本，确认账号状态仍为 `deleted`、学习记录不存在、删除作业为 `completed` 且墓碑保留
界限为完成后 180 天。9D 未修改 6D 生产备份任务；未来真实恢复手册必须把账本作为恢复前置
输入，缺少或校验失败时不得启动恢复后的服务。
