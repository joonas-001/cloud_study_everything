## 2. 实现结果

### 2.1 单一真值的只读能力档案

- 新增 `CapabilityProfileService`，直接投影现有学习执行、活动、评估、范围化证据、真人评审、
  复习任务、Runner 审计和不可变内容锁，不复制或重算证据真值；
- 对 `algorithm@0.3.0` 按 12 域、46 个精确能力 ID 分组；旧版本没有能力图或范围 ID 时明确
  标为 `legacy_unscoped`，不会把旧记录伪装成新能力范围；
- 每个能力分别展示六维等级、记录数、时效、验证方式、Runner 协议／运行时／镜像与测试范围、
  真人评审、来源／保持／人工／版本待办以及“能证明／不能证明”；
- 90 天后的证据只计入过期记录，不再形成当前等级或当前证明陈述；待办与等级分开，待办不会
  覆盖原证据；
- JSON 和 CSV 导出及浏览器本地打印视图均不包含提交正文、代码、输出正文、凭据、金额或公开
  链接，不生成证书。

### 2.2 非虚荣学习分析

- 按能力统计尝试、通过、失败、不确定、纠错、首次尝试、首次确定性通过、最快纠错时间以及
  到期／逾期／通过／失败复测；
- 全局只比较计划估算分钟与已完成任务的估算分钟，明确 `actual_minutes_available=false`；
- 不使用页面停留、点击、完成率、收入、求职或外部动作推断掌握，不生成跨版本百分比、智力
  评分、效率排名或成功概率。

### 2.3 隔离的复习影子评估

- 候选 `review-outcome-candidate@1.0.0` 固定模型、参数、输入 Schema、代码版本和 SHA-256；
- 只读取同一精确技能版本的最小复习结果字段；至少 30 个样本、5 个通过、5 个失败和 4 个
  检查点位置才允许形成内部比较，否则固定返回 `insufficient_data`；
- 乱序输入重放产生相同结果；逐项预测和记忆概率不通过 API 或界面暴露；
- API 固定声明 `affects_tasks=false`、`affects_evidence=false`、
  `affects_user_conclusions=false`；没有任何权威执行路径调用候选评估。

### 2.4 Web 与契约

- 证据中心增加精确范围栏、能力／证据／真人评审摘要、计划偏差、十二域折叠档案、范围记录、
  影子评估边界和 JSON／CSV／打印操作；
- 桌面和移动截图已人工检查，无横向溢出；移动操作保持可达；
- FastAPI OpenAPI 与生成的 TypeScript 契约包含显式档案、分析、隐私和影子评估类型。
