# 云奕学长期产品愿景与第九里程碑之后路线图

> 状态：2026-09-02 规划基线。本文记录长期方向和阶段边界，不构成第九至第十五里程碑的
> 代码实施、外部账号、付费、备案、上架、公开发布或真实用户扩容授权。

## 1. 总体判断

长期建设“离线优先、用户控制数据、可由社区资源包扩展的学习平台”方向合理，也与现有技能包、
供应商适配器、确定性证据和本地运行基础兼容。但必须修正六个容易造成返工或权利冲突的表述：

1. 第九里程碑的 `go` 只能表示完成小规模受控内测后，可以进入下一阶段，不能表示公开上线；
2. 第十里程碑修改认证、隐私或支持相关界面后，必须重跑第九里程碑相应门禁；
3. “国外上线”必须改为国家/地区允许列表，每个法域独立完成隐私、消费者、内容和税务核对；
4. 不得笼统禁止学习者“用云奕学赚钱”，否则会与帮助用户就业、接单和产品化的使命冲突；
5. “上传云端保存”必须拆分为加密备份与多设备同步，不能在密钥、冲突、删除和费用未决定时
   把两者当成一个功能；
6. “网页版”必须区分公网托管网站与浏览器承载的本地应用。一行命令打开的是 loopback 本地
   应用，不代表网站已公开上线，也不替代第十一里程碑的备案、部署和地区放行。

推荐的权利边界是：用户可以利用自己学到的技能和自己创作的成果就业、接单、销售或创业；
未经项目所有者商业许可，不得转售、白标、收费托管、打包销售云奕学软件本身，或将项目代码
作为收费平台的核心组成部分。精确定义仍须由第十一里程碑的许可证与合同包确认。

## 2. 修订后的长期使命

云奕学长期建设为一个离线优先、证据约束、来源可追溯、可扩展的个人学习平台，使用户能够：

1. 在完全离线的本地环境或明确选择的受控托管环境中学习技能；
2. 通过诊断、练习、真实作品、延迟复测和独立验证形成范围化掌握证据；
3. 把已证明的能力用于就业、自由职业或自己的产品，同时不把机会预测宣传为保证收入；
4. 自主控制学习记录、凭据、外部 AI 发送、云端保存、导出、删除和迁移；
5. 通过受管技能包和权限受限的扩展定制学习体验；
6. 在来源、许可证、安全检查和人工治理约束下共享社区学习资源。

“离线优先”不等于所有功能永远离线。它要求没有账号、云端保存、社区或外部 AI 时，核心本地
学习、记录、证据、导出和恢复仍可用；联网功能必须可识别、默认关闭、最少发送并有离线回退。

## 3. 三个相互隔离的产品面

### 3.1 本地离线版

- 单用户、本地数据库、本地凭据存储；
- 核心学习和确定性 Runner 不依赖云奕学账号；
- 社区资源通过签名包或用户明确下载导入；
- 默认无遥测、无外发、无后台账号创建；
- 用户可完整导出、备份、迁移和卸载。
- 普通用户可通过一行命令完成预检、受管迁移、启动、健康检查并打开 loopback 本地网页；
  启动器不得静默取得高权限、安装 Docker/WSL、上传数据或启用外部 AI。

### 3.2 受控托管版

- 多用户身份、数据隔离、隐私权利、支持与运营门禁；
- 用于跨设备访问和受控内测；未来本地版可选云保存必须通过明确契约接入，不能默认绑定账号；
- 与本地版使用相同版本化学习契约，但不共享未授权凭据或本地文件；
- 不得成为离线核心功能的强制依赖。

### 3.3 社区资源服务

- 只承载经过声明和治理的技能包、主题、适配器或其他受支持资源类型；
- 资源作者保留其依法拥有的权利，并授予平台明确、非独占、可执行服务所需的许可；
- 插件权限、网络、文件、Runner、凭据和用户数据访问默认全部拒绝；
- 支持签名、来源、版本、兼容、撤回、举报、下架、恶意包急停和离线安全模式；
- 与主账号、生产数据库和执行基础设施隔离，不能把资源仓库直接当代码执行入口。

## 4. 本地数据、云备份与同步边界

本地版以本地数据库为默认权威副本。用户不登录、不联网、不上传时仍可完成核心学习；启用云端
能力必须经过主动操作，并在操作前展示上传的数据类别、目的、存储地区、接收方、保留/删除、
费用和关闭后的结果。用户必须能够暂停上传、导出云端副本、撤销授权并请求删除。

首选实施顺序是：先验证本地导出/恢复，再验证可选的加密云备份，最后才决定是否建设双向同步：

| 能力 | 含义 | 必须解决 |
| --- | --- | --- |
| 本地备份/恢复 | 用户把本地权威数据复制到自己控制的位置 | 一致性、版本、校验、迁移、恢复演练 |
| 加密云备份 | 用户主动上传可恢复的版本化加密副本，通常是单向的 | 密钥所有权、端到端加密、地区、配额、费用、删除和灾难恢复 |
| 多设备双向同步 | 多个设备都可修改并传播变化 | 上述全部，以及冲突、离线合并、删除传播、设备撤销和历史保留 |

若采用用户持有的端到端加密密钥，服务端原则上不能替用户恢复遗失密钥；若采用服务端托管密钥，
必须明确更大的信任、泄漏和合法访问边界。当前尚未在两者中作出决定。

## 6. 路线图

### 第九里程碑：多用户就绪、受控内测与阶段 go

- 9A–9F 完成决策、用户隔离、认证、隐私、支持、运营和合成候选验收；
- 9G 经单独授权后邀请固定小批量真实成年测试用户，禁止公开注册；
- 9H 收集可撤回、最少化的结构化反馈，修复阻断问题并形成阶段 `go / no-go`；
- `go` 只允许进入第十里程碑，不授权公开发布、商店上架或规模扩张。

### 第十里程碑：第二轮前端体验重设计

- 主题由项目所有者预留，当前保持待命；
- 未收到明确口令前不得设计、改代码、建分支、安装依赖或改变部署；
- 实施时必须保留第九里程碑用户隔离、认证、隐私、支持和账号生命周期语义；
- 完成后重跑受影响的第九里程碑安全、隐私、支持、桌面/移动和无障碍门禁；
- 第十里程碑通过不自动授权第十一里程碑。

### 第十一里程碑：中国内地与海外发布准备及渠道上架

- 11A 确认运营主体、首发国家/地区允许列表、成年人范围、商业模式和法律分类；
- 11B 完成版权、商标、许可证、条款、隐私、可接受使用、投诉和贡献文件；
- 11C 区分一行命令打开的本地网页产品、下载官网、云端账号/保存 API 与可选公网托管 Web
  服务，再完成中国内地与海外部署/数据/备案/隐私分线；
- 11D 建立 GitHub 到 Gitee 的只读、可核验、无敏感状态镜像；
- 11E 为 Android 官网下载建立签名、更新、校验、回滚和 App 备案路径；
- 11F/11G 分别完成 Microsoft Store 与 Apple App Store 的账号、包、隐私和审核要求；
- 每个渠道独立 `go / no-go`，网页版通过不能替代 App 或商店审核。

### 第十二里程碑：本地优先版与可选云保存产品化

- 12A 将开发者运行方式变成一行命令预检、迁移、启动、健康检查并打开本地网页；
- 12B 建立普通用户可安装、更新、本地备份/恢复、迁移和卸载的产品；
- 固定本地/托管数据边界、可移植格式、离线文档、诊断包和安全更新机制；
- 12C 决定云保存的数据类别、密钥模型、地区、供应商、配额、费用、版本、恢复、删除和退出；
- 12D 只在单独授权后验证默认关闭、用户主动启用的加密云备份，本地核心不依赖其可用性；
- 12E 仅在云备份恢复已有真实证据且存在多设备需求后，单独决定是否实现双向同步；
- Windows 优先，其他桌面平台须按真实需求、签名和维护能力另行确认；
- 不以社区、账号、云端保存或外部 AI 作为核心学习启动条件。

### 第十三里程碑：扩展与资源包安全基础

- 在现有技能包上定义公开但受管的扩展 manifest、能力权限、签名和兼容契约；
- 先支持数据型/声明型资源，再评估可执行插件；
- 可执行扩展必须进程/容器隔离，默认断网、无凭据、无任意本地路径和无生产数据库；
- 建立安装预览、权限确认、来源证明、撤回、降级、禁用和安全模式。

### 第十四里程碑：社区资源库与治理

- 建立作者、资源、版本、许可证、来源、审核、举报、撤回和透明度记录；
- 完成内容、版权、商标、恶意代码、隐私和未成年人治理；
- 资源审核和签名不表示教学内容一定正确或插件绝对安全；
- 社区服务故障或关闭时，本地已安装且未撤回的安全资源仍可按明确规则使用。

### 第十五里程碑：生态内测与可持续运营

- 小规模验证作者发布、用户安装、更新、撤回、支持和争议处理；
- 评估免费、赞助、商业许可或其他模式，但不得默认启用付费；
- 验证治理人力、成本、供应链响应和退出方案后，再决定是否公开生态。

第十二至第十五里程碑是方向性编号，不构成实施授权；如第九至第十一里程碑出现新的法律、
成本或架构证据，应保留任务但允许重新排序。

## 7. 当前仍需项目所有者确认

1. 本地一行启动命令的最终名称、支持 Windows/macOS/Linux 的范围、安装包形态，以及
   “DeepSeek Harness”的精确参考链接；已确认只借鉴“一行命令打开本地网页”的体验；
2. 首批海外国家/地区，而不是笼统“国外”；
3. 运营主体采用个人、个体工商户还是公司，以及公开名称；
4. 是否始终只服务成年人；
5. 免费内测后的商业模式和商业许可申请方式；
6. 国内用户数据留在中国内地还是继续进入新加坡，以及是否做区域数据隔离；
7. 社区首版只允许声明型资源，还是未来允许第三方可执行代码；
8. 用户利用“学习成果赚钱”与“商业化云奕学软件本身”的最终合同边界；
9. 云端保存先做单向加密备份还是最终还需要多设备双向同步；
10. 云端密钥由用户还是服务端管理、是否端到端加密，以及供应商、地区、配额和费用；
11. 同步冲突、离线编辑、删除传播、设备撤销、历史保留和恢复规则。

这些决定应分别在第九里程碑 9A、第十一里程碑 11A 和第十二里程碑 12A–12C 确认。在决定前，
不得用默认值启动真实用户扩容、境外公开可用、真实数据上传、社区投稿或商业授权。
