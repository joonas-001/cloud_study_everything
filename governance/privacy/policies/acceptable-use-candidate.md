# 云奕学可接受使用规则候选稿

版本：`2026-09-09-candidate.1`

状态：仅用于 9D 合成环境验证，9G 前仍须完成专业审查并与最终服务条款协调。

## 1. 禁止行为

不得使用云奕学从事违法、欺诈、侵权、骚扰、歧视、剥削或危害他人的活动，也不得：

- 未经授权访问、探测或控制他人账号、数据、设备、网络或服务；
- 绕过身份、权限、费用、来源、供应商、模型、隐私、安全或部署门禁；
- 试图突破 Runner 的断网、非 root、只读根、资源限制、默认 seccomp 或临时目录边界；
- 挂载或获取 Docker Socket、宿主数据库、凭据、仓库或用户任意本地路径；
- 上传恶意代码、凭据、令牌、身份证件、银行资料、完整数据库或无必要的敏感附件；
- 利用自动化进行垃圾投递、批量联系、虚假申请、平台操纵、交易或其他未经用户逐次确认的外部动作；
- 伪造能力证据、真人评审、来源、市场结论、收入或审计记录；
- 删除、掩盖或误述必要的来源、许可、局限、候选状态或证据等级。

## 2. 软件商业化边界

未经项目所有者另行商业许可，不得转售、白标、收费托管、打包销售或把云奕学软件本身用于未经授权的商业化。不得把这一边界扩大解释为限制用户合法利用自己学到的技能或自己创作的成果就业、接单、销售或创业。

## 3. 外部服务与数据最小化

只有用户主动选择且独立门禁全部满足时，才可向批准的外部服务发送完成当前功能所必需的最少数据。不得静默启用、重试后切换供应商、扩大接收方或发送范围。9D 中 Clerk、DeepSeek、真实来源和邮件均未激活。

## 4. 处置原则

疑似违反规则时，应优先限制具体功能、保存最少必要安全证据并提供可审查原因；不得借处置收集无关敏感数据。真实用户环境中的通知、申诉、恢复和终止机制须在 9G 前经专业审查和明确确认。
